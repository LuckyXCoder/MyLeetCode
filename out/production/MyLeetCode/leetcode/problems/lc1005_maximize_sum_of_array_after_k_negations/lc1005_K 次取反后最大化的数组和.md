## 题目描述

给你一个整数数组 `nums` 和一个整数 `k` ，按以下方法修改该数组：
  * 选择某个下标 `i` 并将 `nums[i]` 替换为 `-nums[i]` 。
重复这个过程恰好 `k` 次。可以多次选择同一个下标 `i` 。
以这种方式修改数组后，返回数组 **可能的最大和** 。

**示例 1：**

**输入：** nums = [4,2,3], k = 1

**输出：** 5

**解释：** 选择下标 1 ，nums 变为 [4,-2,3] 。

**示例 2：**

**输入：** nums = [3,-1,0,2], k = 3

**输出：** 6

**解释：** 选择下标 (1, 2, 2) ，nums 变为 [3,1,0,2] 。

**示例 3：**

**输入：** nums = [2,-3,-1,5,-4], k = 2

**输出：** 13

**解释：** 选择下标 (1, 4) ，nums 变为 [2,3,-1,5,4] 。

**提示：**
  * `1 <= nums.length <= 104`
  * `-100 <= nums[i] <= 100`
  * `1 <= k <= 104`

## 参考答案

```java
class Solution {
    
    /**
     * @description 小根堆实现：利用贪心思想，优先翻转最小负数以最大化总和。
     **/
    public static int largestSumAfterKNegations(int[] nums, int k) {
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        int sum = 0;
        for (int num : nums) {
            sum += num;
            minHeap.add(num);
        }
        while (!minHeap.isEmpty() && k-- > 0) {
            int minNum = minHeap.poll();
            if (minNum == 0) break;
            sum -= minNum << 1;
            minHeap.add(-minNum);
        }
        return sum;
    }
    
    /**
     * @description 数组实现：利用贪心思想，优先翻转最小负数以最大化总和。
     **/
    public int largestSumAfterKNegations(int[] nums, int k) {
        //找数组中值最小的那个，这样子加上-号后能保证当前修改后数组是最大的（这里是强制修改）
        //这样子能保证k次修改后，数组和是最大的
        //进行k次替换
        for(int i=0;i<k;i++){
            int minindex=MinIndex(nums);
            nums[minindex]=-nums[minindex];
        }

        int sum=0;
        for(int num:nums){
            sum+=num;
        }
        return sum;

    }

    public static int MinIndex(int[] nums) {
        int min = nums[0];
        int index = 0;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] < min) {
                min = nums[i];
                index = i;
            }
        }
        return index;
    }
}
```

## 一刷思路

### 思路一

递增排序后依次将最小的负数变为正数，如果没有次数直接求和。

如果还有次数，多余次数为偶则所有数直接相加，多余次数为奇则其余数和减去最小的数。

但是考虑到瓶颈，排序的时间复杂的为： $n \log n$ ，感觉不太妙

遍历求和时间复杂度：$n$ （相对排序操作可以忽略，非瓶颈）

### 思路二

考虑到上面的思路，只需要找到最小的 $k$ 个数即可。

转换为 `Top K 问题`，自然想到了长度为 $k$ 的大根堆，每次弹出最大的来找到最小的数。

小根堆在 Java 中是 `PriorityQueue` 优先队列，重写排序方法。

找对最小 $k$ 个数 只需要将所有数的和，减去最小 $k$ 个数的二倍即可。
